# Assets

This demo references public Pexels image URLs directly from `index.html` and `js/script.js`, so no image files need to be downloaded. To use local images, add them here and replace image URLs with relative paths such as `assets/saree.jpg`. Keep descriptive alt text in the category, product, hero, and gallery data.

If a hosted image fails, the storefront hides that image while preserving its reserved layout. Confirm that images are licensed and approved for the intended storefront before production.
